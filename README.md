# 🏥 MediAI – AI-Powered Healthcare Appointment Platform

MediAI is a full-stack healthcare appointment platform designed to simplify the process of discovering doctors and booking appointments.

The application combines a modern React frontend with a Node.js/Express backend, MongoDB for data storage, and Google Gemini AI for intelligent healthcare-related assistance.

## ✨ Features

- 👤 User registration and login
- 👨‍⚕️ Doctor selection
- 📅 Appointment date selection
- ⏰ Appointment time selection
- 📝 Reason for appointment
- 📋 Appointment management
- 🤖 AI-powered assistance using Google Gemini
- 🔐 Backend API with Node.js and Express
- 🗄️ MongoDB database integration
- 📱 Responsive and user-friendly interface
